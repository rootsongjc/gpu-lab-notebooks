# GPU Lab Notebooks

Colab notebooks for the *Kubernetes 上的 GPU 实验室* course (Colab 预备篇).
Each notebook mirrors one chapter at https://jimmysong.io/zh/book/gpu-lab-on-kubernetes/colab/ and is regenerated from the chapter source by
`scripts/content/build-colab-notebooks.py` in the website repo; edit the chapter, not the notebook.

All labs target the free **Tesla T4** runtime (Runtime → Change runtime type → T4 GPU).
